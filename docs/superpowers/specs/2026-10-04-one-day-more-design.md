# One Day More — design

The user requests an ambitious Les Misérables kinetic typography artwork with music and explicitly delegates all remaining creative choices. Build a full-screen browser film, not a slideshow. Palette: soot, warm ivory, revolutionary vermilion; serif title, condensed dramatic type, archival monospace details. Eight deterministic chapters move from isolation through love, conflict and revolt into a collective finale. Original interpretive words accompany the song title; do not reproduce the full copyrighted lyrics.

Use a high-DPI Canvas renderer with particles, revolving circles, barricade geometry, layered typography and scene transitions. A single media clock drives every scene, seek and pause. Controls: play/pause, scrub, chapter selection, volume, fullscreen, reduced-motion setting and soundtrack selection. Keyboard: Space, arrows, M, F, Escape.

Music: visible YouTube IFrame Player for TUNE's 25th Anniversary recording wNNBrg4u9d0, synchronized through its actual playback time. Include local audio import and an explicitly labelled original instrumental study as an offline option. Never claim the original instrumental is the musical's recording. Surface blocked embed errors and offer local audio; do not silently substitute soundtracks. Responsive mobile layout; safe local object URL disposal; no microphone, account or backend required. Build with Vite, vanilla ES modules and Web Audio. Keep all source assets below 20MB.

Validate deterministic chapter bounds, timeline seek/clamp, paused clock, end behavior; build and inspect desktop/mobile actual rendering and playback controls. Document Internet requirements and music sources.
